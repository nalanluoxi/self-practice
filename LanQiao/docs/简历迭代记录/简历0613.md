- **三级限流 + 动态自适应限流体系建设**｜Sitemap 环路大站挤兑小站，固定阈值无法感知线程池负载。限流侧三级递进：集群层与单机层** Rhino **保护下游，站点层 Redis+Lua 令牌桶精确限频，无效流量前置拦截。自适应侧使用** Daemon 线程**采样**线程池健康度**，**环形缓冲**连续 3 次越过** 80% 水位**触发配额收缩，避免频繁调整线程池大小的抖动。调度产出大站挤兑小站问题基本解决.

## icon:project 项目经历 Project Experience
- **项目名称**：**智析RAG**

基于**Spring AI**构建企业级检索增强生成（RAG）对话系统，支持 **PDF/Markdown/TXT** 多格式文档解析入库与语义问答，涵盖**多通道检索**、**意图分类**、**熔断路由**、**对话记忆**等核心模块。
- **多通道并行检索** 基于 CompletableFuture 同时发起**全局向量检索与意图定向检索**两条通路，结果意图定向优先合并去重，有效提升召回率与检索精度。

- **Chat / Embedding 双维熔断路由** 为 Chat 与 Embedding 分别实现**多模型候选三态熔断器**，连续失败自动熔断、定时探测恢复；Chat 路由额外引入首包探测，拦截空流响应触发切换，实现 AI 服务零感知故障转移。

- **意图树三级分类缩小检索空间** 构建**领域→类目→话题三级意图树**，通过 LLM 对用户查询分类后将检索范围收敛至目标知识库；对闲聊/系统意图短路处理，跳过向量检索直接回复，降低无效调用开销。

- **LLM 重排序提升上下文质量** 向量检索召回后，用 LLM 对每个文档片段与问题的语义相关性打分，按分数降序取 Top-3 注入 Prompt，相比纯余弦相似度排序显著提升答案准确率。

- **持久化对话记忆与摘要压缩** 持久化多轮对话记忆基础上，当会话消息超过阈值时自动调用 LLM 压缩最旧的一半消息为摘要写回数据库，在保留长期上下文的同时控制 Token 消耗。
