作为后端参与 Friday 数据组日常开发迭代，主要负责网页抓取，为 LongCat 大模型训练搭建预训练语料库，建立网页抓取-解析-清洗全流程体系，参与内部 sitemap 新链发现环路的需求开发。

个人产出：

流量智能调度与自适应限流优化
针对大站点挤占资源导致小站任务积压的问题，设计并落地"集群层–单机层–Redis精确层"三级限流体系，前置拦截无效流量，实现站点级抓取频率的公平调度；进一步构建"线程池健康度–限流阈值"联动模型，实现分钟级自适应调频，峰值 QPS 达 1417，推动团队英文新链留存量从 2000 万增长至 1.2 亿。

环路架构与并发能力提升
为突破单线程处理瓶颈与低吞吐限制，将原有架构重构为异步线程池模型并扩容 Mafka 集群，推动日新链发现量从 2–3 亿跃升至峰值 75 亿，集群 QPS 由不足 10 提升 16 倍至 400+。

压缩包处理能力拓展
新增 .gz 压缩包解压解析模块，日均处理 400 万+压缩包，贡献 4%–16% 新增链接，推动日产出从 3.79 亿激增至 52.6 亿（14 倍增长）。

智能投递策略重构
基于新链产出效果构建站点评分体系，动态调整 Sitemap 抓取频次，高频优质站点加速、低效站点降载，显著提升整体发现效率与资源利用率。

策略拦截打压
针对日志系统中发现的作弊站、垃圾站，搭建 DSL 规则引擎支持正则热更新，结合 URL 指纹切割识别垃圾链接，有效拦截 90% 垃圾站点，提升新链发现质量。

JS 抓取引擎升级
基于多进程抓取实测（Selenium vs Playwright），选用 Playwright 重构 JS 抓取引擎，引入 Browser Context 技术与自定义线程池，彻底去除探活与轮询逻辑，大幅提升动态页面抓取稳定性与并发效能。

网页截图抓取服务建设
面向多模态大模型训练数据需求，独立设计并实现网页截图全链路服务：基于 Playwright 引擎渲染截图，构建独立线程池（与 Sitemap 环路完全隔离），截图结果上传 S3；集群 490 台机器整体吞吐约 1000 条/分钟，产出数据用于训练大模型「看图写代码」多模态能力。

sitemap 环路监控体系建设
搭建基于 Redis 小时粒度统计的精细化监控体系，精确追踪每批次抓取量与链接发现数，及时发现堆积、失败率高、无效站点多等问题，推动后续无效站点治理落地。
