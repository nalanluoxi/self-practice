## 三、问题归因与建议

| 问题 | 根因 | 建议 |
|------|------|------|
| 403 页面被当正常结果存储 | 未检测响应状态码过滤错误页 | Phase1 检测 HTTP 状态码，4xx 页面标记异常不落盘 |
| 纯 JS 渲染页面无 `<body>` | `LOAD` 事件触发时 JS 尚未执行完成 | 增加 `waitForSelector('body')` 或 `domcontentloaded` 后额外等待 |
| `data:image/base64` 被记录为资源 | `onResponse` 回调未过滤 `data:` URL | 在资源记录入口处增加 `if (url.startsWith("data:")) continue` |
| CDN 图片处理 URL 误抓 | URL 形如 `x-oss-process=image/format`、`s_webp/` 等，实为服务端指令 | 建立 CDN 处理 URL 特征黑名单，记录前过滤 |
| 源站资源 404/不可访问 | 源站历史资源已失效 | 属正常现象，可在统计时按域名聚合失败率监控 |
