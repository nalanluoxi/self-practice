# Markdown 语法速查

## 1. 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

---

## 2. 文字样式

```markdown
**粗体**
*斜体*
***粗斜体***
~~删除线~~
`行内代码`
```

效果：**粗体** | *斜体* | ***粗斜体*** | ~~删除线~~ | `行内代码`

---

## 3. 链接与图片

```markdown
[链接文字](https://example.com)
[链接文字](https://example.com "悬停提示")

![图片描述](图片路径)
![图片描述](https://example.com/img.png "悬停提示")
```

示例：[advisors](https://docs.spring.io/spring-ai/reference/api/advisors.html)

---

## 4. 列表

**无序列表**（`-` / `*` / `+`）：
```markdown
- 项目一
- 项目二
  - 嵌套项
```

**有序列表**：
```markdown
1. 第一步
2. 第二步
3. 第三步
```

**任务列表**：
```markdown
- [x] 已完成
- [ ] 未完成
```

---

## 5. 代码块

**行内代码**：
```markdown
`代码内容`
```

**多行代码块**（指定语言可高亮）：
````markdown
```java
public static void main(String[] args) {
    System.out.println("Hello");
}
```
````

常用语言标识：`java` `python` `bash` `sql` `json` `xml` `yaml` `javascript` `html` `css`

---

## 6. 引用

```markdown
> 这是一段引用
>
> > 嵌套引用
```

> 这是一段引用
> > 嵌套引用

## 7. 表格

```markdown
| 列1   | 列2   | 列3   |
|-------|:-----:|------:|
| 左对齐 | 居中  | 右对齐 |
| 内容   | 内容  | 内容   |
```

| 列1   | 列2   | 列3   |
|-------|:-----:|------:|
| 左对齐 | 居中  | 右对齐 |
| 内容   | 内容  | 内容   |

---

## 8. 分割线

```markdown
---
***
___
```

---

## 9. 换行与段落

- 段落之间空一行
- 行末加**两个空格**再回车 = 软换行
- 直接回车不换行（渲染后连在一起）

---

## 10. 转义字符

在特殊字符前加 `\` 可以显示原字符：

```markdown
\* \` \# \[ \] \( \) \_ \~ \>
```

---

## 11. 锚点跳转（页内导航）

```markdown
[跳转到标题](#标题文字)

## 标题文字
```

> 中文标题转为锚点时全部小写，空格替换为 `-`

---

## 12. HTML 内嵌

Markdown 支持直接嵌入 HTML：

```markdown
<br> 换行
<kbd>Ctrl</kbd> + <kbd>C</kbd>
<details>
  <summary>点击展开</summary>
  隐藏内容
</details>
```

效果：<kbd>Ctrl</kbd> + <kbd>C</kbd>

---

## 13. 脚注

```markdown
这里有一个脚注[^1]

[^1]: 这是脚注内容
```

---

## 14. 数学公式（部分渲染器支持）

```markdown
行内公式：$E = mc^2$

块级公式：
$$
\sum_{i=1}^{n} x_i = x_1 + x_2 + \cdots + x_n
$$
```
