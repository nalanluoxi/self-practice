# 截图抓取 MQ 消息体大小估算

> 基于 874 条实际抓取样本（Output_EN_500_TEST_03 / Output_SAM_500_TEST_03，合并统计）
> 以及 500 条 sampled_urlList.csv URL 长度分布
> 估算策略：以最大实测值为基准，乘以冗余系数留出空间

## 二、结果消息（llm_screenshot_result）

### 2.1 html 字段实测

| 指标 | 值 |
|------|----|
| 样本量 | 874 条 |
| 实测最大值 | **6,407,806 B（≈ 6.1 MB）** |

### 2.2 html 大小控制策略（buildResultMessage）

压缩判断基于 **原始 htmlBytes 字节数**，在构建消息体时执行，非序列化后判断：

| 阶段 | 触发条件 | 处理方式 |
|------|---------|---------|
| 第一阶段 | `htmlBytes > 1 MB` | 对 `html` 做 **zlib + base64** 压缩，设 `htmlCompressed=true` |
| 第二阶段 | 压缩后字符串长度 **> 4 MB** | `html` 置为提示语（"页面内容过大，html 已丢弃，请通过 s3DirKey 获取完整内容"），`Cat.logEvent("screenshot.html.too.large")` 打点告警 |

> **注意**：第二阶段丢弃后 html 字段不为 null，而是固定提示语（约 40 B），下游需通过 `s3DirKey + "index.html"` 从 S3 读取完整内容。

**zlib 对 HTML 文本的压缩效果**：HTML 重复结构多，实测压缩率通常在 **10%~30%**（即压缩后为原始大小的 10%~30%）。

| 原始 html 大小 | 压缩后估算（× 30%） | 压缩后估算（× 10%） | 是否超 4 MB 丢弃 |
|--------------|------------------|------------------|----------------|
| 6.1 MB（实测最大） | ≈ 1.8 MB | ≈ 0.6 MB | 否，正常发送压缩内容 |
| ~13 MB 以上 | > 4 MB | — | 是，html 丢弃走 S3 |

> 当前实测样本最大 6.1 MB，压缩后约 0.6~1.8 MB，**远低于 4 MB 丢弃阈值**。

### 2.3 结果消息完整字段估算（含压缩策略后）

| 字段 | 最大估算 | 备注 |
|------|---------|------|
| `url` | ≈ 750 B | 248 B × 3 |
| `domain` | ≈ 75 B | |
| `httpCode` | ≈ 12 B | |
| `status` | ≈ 30 B | |
| `s3DirKey` | ≈ 240 B | `screenshot/{yyyyMMdd}/{dirName}/` |
| `errorReason` | ≈ 400 B | |
| `reqId` | ≈ 120 B | |
| `ext` | ≈ 300 B | |
| `htmlCompressed` | ≈ 12 B | |
| JSON 结构符 | ≈ 300 B | |
| **元数据小计** | **≈ 2.2 KB** | |
| **`html` 字段（代码硬上限）** | **< 4 MB** | 压缩后超过则丢弃，代码保证 |
| **消息体硬上限** | **< 4 MB + 2.2 KB ≈ 4 MB** | 由代码逻辑保证，非估算值 |

### 2.4 申请建议

| 场景 | 消息体大小 | 说明 |
|------|-----------|------|
| 正常（压缩后 ≤ 4 MB） | **< 4 MB**（代码硬上限） | html 为 zlib+base64 压缩内容 |
| 兜底（压缩后 > 4 MB，html 丢弃） | **≈ 2.2 KB** | html 为固定提示语约 40 B |

> **消息体上限由代码逻辑硬性保证不超过 4 MB**（压缩后 > 4 MB 则丢弃 html），而非依赖压缩率估算。
> 申请 **4 MB** 严格满足，若希望留出运维冗余可申请 **5 MB**。

## 三、Topic 申请参数汇总

| 参数 | `llm_screenshot_request` | `llm_screenshot_result` |
|------|--------------------------|------------------------|
| **单条消息大小上限** | **1 KB** | **4 MB（代码硬上限）/ 5 MB（含运维冗余）** |
| 消息格式 | JSON | JSON |
| html 压缩 | — | zlib+base64，原始 > 1 MB 触发；压缩后 > 4 MB 丢弃 html 走 S3 |
| 预估 QPS | 按批量规模填 | 同 request（1:1） |
| 保留时长建议 | 3 天 | 7 天 |
| 生产者 | llm-crawler-server | llm-crawler-server |
| 消费者 | llm-crawler-server（ScreenshotRequestConsumer） | Spark 任务 → Hive |
