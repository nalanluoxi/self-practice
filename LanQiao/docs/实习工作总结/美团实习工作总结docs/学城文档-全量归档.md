  - **投递评估方案**：统计每日发送的不同等级sitemap条数，与当日频度等级表比对；或写入临时表进行精细化比对

### 17. Agent-Sitemap频度调度评分优化方案（精简版） (ID: 2756889378)
- **日期**: 2026-04-15
- **核心内容**: 重新设计sitemap频度调度评分机制，解决现有0/1信号粗糙、一天只投递一次、未考虑内容质量、状态维护成本高的问题。
- **关键数据**:
  - **新方案数据流**：SitemapBloomFilterJob（写入新链接表含sitemapurl/dispatch_ts）→ UpdateFrequencyTableJob（核心打分）→ FrequencyDeliverySitemapJob（投递）
  - **打分公式**：`compositeScore = 0.7 × newUrlScore + 0.3 × fuzzyScore`
  - **fuzzyScore**：`0.5 × rateScore（留存率分） + 0.5 × scaleScore（规模分）`
  - **newUrlScore**：昨日命中批次数 / 6（每天投递6次）
  - **留存率分rateScore**：≥60%→1.0, 40-60%→0.75, 20-40%→0.5, 5-20%→0.25, <5%→0.0
  - **规模分scaleScore**（log压缩）：1条→0.06, 100条→0.40, 1000条→0.60, 10000条→0.80, ≥10万条→1.0
  - **等级映射**：≥0.75→grade1(HIGH), ≥0.50→grade2(MIDDLE), ≥0.25→grade3(LOW), <0.25→grade4(DISUSE)
  - **升降级保护**：每次最多升1级，降级不限速
  - **投递频次**：grade1(6次/天: 00/04/08/12/16/20), grade2(4次/天: 00/06/12/18), grade3(2次/天: 00/12), grade4(不投递)
  - **黑名单过滤**：整站拦截（domain级，色情/赌博/小说等）+ 路径拦截（pattern级，工具页/入口页）
  - **无数据默认值**：domain当天不在留存表中，默认给0.35
  - **典型案例**：
    - 大新闻站（BBC）：6/6命中，留存率40%，日均200万条 → grade1
    - 中型科技媒体：4/6命中，留存率50%，日均5万条 → grade1
    - 小博客：2/6命中，留存率80%，日均1条 → grade3
    - 垃圾内容农场：6/6命中，留存率1%，日均5000条 → 黑名单拦截grade4
    - 长期无更新站：0/6命中，留存率30%，日均500条 → grade4
  - **改造Job**：SitemapBloomFilterJob（新增列透传sitemapurl/dispatch_ts）、UpdateFrequencyTableJob（核心逻辑重写）、FrequencyDeliverySitemapJob（单次改循环6次，MQ消息量预计增加3-6倍）
