## 六、打分公式参数说明

```
compositeScore = 0.5 × newUrlScore + 0.5 × fuzzyScore
fuzzyScore     = 0.5 × rateScore   + 0.5 × scaleScore
```

| 参数 | 计算来源 | 含义 |
|:--|:--|:--|
| `newUrlScore` | Bloom 去重新链接表（日均命中批次数/6） | 新链接产出效果 |
| `rateScore` | `llm_crawler_domain_save_info`（留存量/抓取数） | 留存率得分 |
| `scaleScore` | `llm_crawler_domain_save_info`（留存量 log 压缩） | 站点规模得分 |
| **降级保护** | 每次最多降 1 级 | 防止数据波动导致等级快速跌落 |
| **domain 无数据** | 默认 fuzzy_score = 0.35 | 静默回退值 |

### 等级阈值

| compositeScore | 等级 |
|:--:|:--:|
| ≥ 0.75 | grade 1 (HIGH) |
| ≥ 0.50 | grade 2 (MIDDLE) |
| ≥ 0.25 | grade 3 (LOW) |
| < 0.25 + rate ≥ 0.01 | grade 4 (DISUSE) |
| 其他 | grade 5 (PENDING) |
