# 截图抓取服务建设

> **背景**：多模态大模型训练需要大规模高质量网页截图，用于训练"看图写代码（HTML/CSS）"能力。从 CC 筛选出一批高质量 URL，抓取后做截图返回，交给大模型训练"根据截图写前端代码"。

---

## 一、抓取服务整体架构

```
Mafka（URL 任务）
  → ScreenshotRequestConsumer（前置过滤 + 线程池分发）
      → ScreenshotService.submit()
          → ScreenshotPlaywrightService.crawlScreenshot()
              Phase1: navigate → onResponse 监听（JS/CSS/图片/字体）
                      + supplementFontsFromCss()     ← CSS @font-face 字体兜底
                      + supplementImagesFromHtml()   ← HTML img 图片兜底
                      + supplementScriptsAndStylesFromHtml() ← JS/CSS 兜底
              Phase2: 多视口截图 + JS_DOM_EXTRACT
                      → ClickableElement 可交互元素识别
                      → annotated_screenshot（标注图）
          → 上传 S3（边抓边上传，不攒内存）
          → 发 MQ（ScreenshotResultMessage，含 uploadedKeys JSON 数组）
```

---

## 二、技术方案详述

### 2.1 Playwright 引擎集成

**引擎选型**：经过多进程网页抓取实测对比（Selenium vs Playwright），Playwright 更优：
- 避免不稳定的等待逻辑
- 原生支持 Browser Context（轻量化多租户模拟）
- 对最新版 Chrome 完美兼容
- 彻底去除了 Selenium 时代的探活与轮询逻辑

**前置工作**：Playwright 部署时面临底层库（glibc、gcc）版本过低的兼容性挑战，本地测试成功但线上无法运行。完成了服务器 glibc 及 gcc 核心库的深度升级，并将升级流程沉淀为**标准化自动化脚本**，实现全量服务器批量化升级。

### 2.2 三线路 Playwright 实例管理

```
INSTANCES_137：海外普通（OVERSEA_NORMAL），Chrome 137，新加坡时区
INSTANCES_136：海外高级（OVERSEA_ADVANCED_LINE），Chrome 136，英国时区
INSTANCES_130：国内普通（MAINLAND_NORMAL），Chrome 130
```

- 三条线路各自独立 **ThreadLocal**，线程间不共享实例
- **实例存活**：5 分钟后刷新（`PLAYWRIGHT_INSTANCE_SURVIVE_MAX_TIME = 5min`），每次使用时续期
- **清理线程**：每 5 分钟扫描 `instanceMap`，关闭过期实例

### 2.3 两层线程池隔离

| 线程池 | 变量名 | Lion 配置 | 说明 |
|:--|:--|:--|:--|
| 外层消费池 | `ScreenshotRequestConsumer.EXECUTOR` | `screenshot_thread_num` | MQ 消费 → 转发/提交任务 |
| 内层下载池 | `ScreenshotPlaywrightService.DOWNLOAD_TASK_POOL` | `screenshot_download_thread_num` | 实际执行 Playwright 抓取 |
| 补充下载池 | `ScreenshotPlaywrightService.SUPPLEMENT_POOL` | `screenshot_supplement_thread_num` | 图片/字体/CSS/JS 兜底并行下载（与下载池完全隔离防死锁） |

### 2.4 资源收集策略（Phase1）

| 阶段 | 方式 | 说明 |
|:--|:--|:--|
| 主收集 | `onResponse` 监听 | navigate 过程中拦截 JS/CSS/图片/字体响应，立即 `body()` |
| 状态码 200 但 body 为空 | `downloadWithProxy` 重试 | 304 缓存命中或网络抖动，主动重拉 1 次 |
| 字体兜底 | `supplementFontsFromCss` | ph-css 解析 `@font-face src url()`，下载 Chrome 懒加载未触发的字体 |
| 图片兜底 | `supplementImagesFromHtml` | Jsoup 解析 `img[src/srcset/data-src]`、`picture source[srcset]`，取差集并行下载 |
| JS/CSS 兜底 | `supplementScriptsAndStylesFromHtml` | 解析 `<link rel="stylesheet">`、`<script src>`，取差集并行下载 |
| CSS 内存回写 | JS_DOM_EXTRACT 注入脚本 | 将浏览器内存中已计算的 CSS 直接写回 HTML，解决动态加载 CSS 缺失问题 |

### 2.5 S3 目录结构

```
screenshot/{yyyyMMdd}/{urlSafeName}_{md5前8位}/
├── index.html                    ← 页面 HTML（含 CSSOM 回写内联样式）
├── resources.tsv                 ← 资源清单（url\tlocalName\ttype\tstatus）
├── assets/                       ← 静态资源
│   ├── *.js / *.css / *.img / *.font
└── viewport_{n}/                 ← 第 n 个视口（phase2 截图）
    ├── screenshot.png
    ├── annotated_screenshot.png  ← 标注可交互元素框（红色矩形）
    └── clickable_elements.json  ← 可交互元素坐标/类型列表
```

## 三、典型问题与解决方案

### 3.1 中文站点乱码问题

**现象**：截图中中文字符显示为方块/乱码。
**原因**：服务器未安装中文字体包。
**解决**：在服务器上安装对应中文字体包（wqy-zenhei、noto-cjk 等），确保 Playwright 中文页面截图显示正常。

### 3.2 字体缺失问题

**现象**：页面截图中自定义字体无法加载，显示为系统降级字体，页面还原度低。
**分析**：Chrome 对字体资源采用懒加载策略，`onResponse` 只在字体实际被浏览器请求时才能拦截；但某些字体在初始 navigate 过程中不触发请求。
**解决**：通过 `supplementFontsFromCss()` 主动解析 CSS 中所有 `@font-face` 规则，提取字体 URL 后主动下载（不依赖浏览器是否触发请求）。
**效果**：字体缺失问题基本解决（2026.06 周报确认）。

### 3.3 图片可用率问题

**现象**：图片下载成功率约 70%，存在部分图片无法获取。
**原因**：懒加载图片（`IntersectionObserver` 触发）在初始 navigate 时未加载；部分图片响应体为空。
**解决**：
- `supplementImagesFromHtml()` 解析 HTML 中所有 img 标签，取差集后并行补充下载
- 结合滑动窗口触发页面滚动，触发懒加载图片
- 配合二次抓取机制
**效果**：图片可用率约 70%（持续优化中）。

### 3.4 CSS 缺失问题

**现象**：动态加载的 CSS（`loadCSS`、`async style`）无法通过 `onResponse` 拦截，页面离线重现时样式丢失。
**解决**：注入 JS 脚本（JS_DOM_EXTRACT），将浏览器内存中已计算的 CSS（CSSOM）直接序列化写回 HTML 的 `<style>` 标签，实现 CSS 内存回写。
**效果**：CSS 缺失问题基本解决（2026.06 周报确认）。

## 六、截图链路关键 MQ 消息格式

**请求消息** → `ScreenshotRequestConsumer`：
```json
{
  "reqId": "xxx",
  "url": "https://example.com",
  "type": "screenshot",
  "proxyType": "OVERSEA_NORMAL"
}
```

**结果消息** → 下游：
```json
{
  "reqId": "xxx",
  "url": "https://example.com",
  "uploadedKeys": "[\"screenshot/20260601/example_a1b2c3d4/index.html\", ...]",
  "httpCode": 200,
  "error": null
}
```
