> 最后更新：2026-05-27

## 流程一：通用网页抓取流

```
上游调用方（Thrift RPC / Mafka MQ）
  → CrawlerRequestConsumer#receive（Mafka 消费）
      ├─ 流量采样（domesticCrawlRatio / overseaCrawlRatio）→ 丢弃 or 继续
      ├─ 灰度路由判断
      │    ├─ isJsSpiderGray=1  → sendJsCluster（HTTP 转发到 JS 集群）
      │    ├─ isCamoufoxGray    → CamoufoxDownloader（指纹浏览器集群）
      │    ├─ isAntibotGray     → AntibotDownloader（Antibot 集群）
      │    └─ 默认              → CrawlerService#download（本机执行）
  → CrawlerService#download
      ├─ 选 Proxy（ProxySetProvider）
      ├─ 执行 Downloader（WebDownloader / JSDownloader / PlaywrightDownLoader）
      ├─ 下载成功 → CrawlResultPublishService / TimeCrawlResultPublishService / DocCrawlResultPublishService（发 MQ）
      └─ 下载失败 → 重试（最多 retryNum 次）→ CAT 打点

输入：CrawlerRequest（url / domain / downloader / proxy / unit / group）
输出：CrawledResult → Mafka MQ（下游消费存储）
```

## 流程二：Sitemap 发现流

```
上游调度系统
  → Mafka MQ（SitemapRequest）
  → SitemapRequestConsumer#receive（消费）
      ├─ 预过滤（URL 格式 / 过期消息 / 黑名单 / 正则 / Redis 去重 / 限流）
      └─ addRequestToThreadPool（EXECUTOR）
  → SitemapService#download
      ├─ 下载 robots.txt（SitemapDownloader） → 解析 Allow/Disallow + Sitemap 链接
      ├─ 解析 sitemap.xml（crawlercommons SitemapParser）
      │    ├─ 普通 sitemap → 提取 URL 列表
      │    └─ sitemap index → 递归解析子 sitemap
      ├─ URL 过滤 + 布隆去重（Redis）
      ├─ 写 Redis 去重标记（llm_sitemap_url）
      ├─ 写 S3（sitemap 数据持久化）
      └─ SitemapPublishService → 投递 URL 到下游 MQ

输入：SitemapRequest（url / domain / type / ext[dispatchTs, batchId]）
输出：解析出的 URL 列表 → Mafka MQ（下游 URL 队列） + S3 存储
```

## 流程三：截图 + HTML 抓取流

```
上游调度系统
  → Mafka MQ（ScreenshotRequest）
  → ScreenshotRequestConsumer#receive（消费）
      ├─ 预过滤（URL 合法性 / domain 提取 / 黑名单 / URL 格式）
      └─ addRequestToThreadPool（EXECUTOR）
  → ScreenshotRequestConsumer#forwardToCluster
      ├─ screenshotClusterIp 非空 + 灰度命中 → HTTP 转发到截图专属集群
      └─ 否则本机执行 → ScreenshotService#submit
  → ScreenshotService#submit
      ├─ 选 Proxy（crawlerService.getProxy）
      ├─ ScreenshotPlaywrightService#crawlScreenshot（Playwright 渲染）
      │    ├─ Phase1：初次渲染，获取页面截图 + HTML
      │    └─ Phase2（可选）：滚动/二次渲染，获取更完整资源
      ├─ 上传截图 PNG → S3（screenshot 目录）
      ├─ 上传 HTML → S3（html 目录）
      ├─ 上传资源文件（CSS/JS/图片）→ S3
      └─ ScreenshotPublishService → 发送结果消息到 MQ（包含 S3 路径列表）

输入：ScreenshotRequest（url / domain / host / retryTimes）
输出：ScreenshotResultMessage（S3 路径列表）→ Mafka MQ + S3 存储
```

## S3 存储路径规范

| 内容类型 | Bucket | Path 模式 |
|---------|--------|-----------|
| Sitemap 数据 | `llm-web-sitemap` | `data_storage/{domain}/...` |
| 网页 HTML | `llm-web-sitemap` | `page_storage/{date}/{urlHash}/index.html` |
| 截图 PNG | `llm-web-sitemap` | `screenshot/{date}/{urlHash}/screenshot.png` |
| 静态资源 | `llm-web-sitemap` | `screenshot/{date}/{urlHash}/resources/` |

## 代理路由逻辑

```
CrawlerRequest
  → 是否海外域名（isNotZhHost）→ 选海外代理（overseaProxy）
  → 是否命中 Camoufox 灰度   → 转发 Camoufox 集群
  → 是否命中 Antibot 灰度    → 转发 Antibot 集群
  → 是否命中 JS Spider 灰度  → HTTP 转发 JS 集群
  → 默认                    → 本机 + ProxySetService 代理池
```
