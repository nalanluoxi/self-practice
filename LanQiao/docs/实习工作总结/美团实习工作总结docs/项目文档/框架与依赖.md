# 框架与依赖

> 最后更新：2026-05-27

## MDP 脚手架（美团内部）

| 组件 | 说明 |
|------|------|
| `mdp-parent 2.9.8` | 根 POM，统一管理版本 |
| `@MdpConfig` | 注入 Lion 配置中心的动态配置，支持热更新 |
| `@MdpConfigListener` | 监听 Lion 配置变更，动态调整线程池大小等 |
| `@MdpMafkaMsgReceive` | 声明 Mafka 消息消费入口方法 |
| `@MdpThriftServer` | 声明 Thrift RPC 服务实现类 |
| `mdp-boot-starter-mafka` | Mafka（美团 Kafka 封装）消费/生产 |
| `mdp-boot-starter-cellar` | Cellar（Tair）分布式缓存 |
| `mdp-boot-starter-squirrel` | Squirrel（Redis）缓存 |
| `mdp-boot-starter-s3plus` | S3 对象存储（兼容 AWS S3 API） |
| `mdp-boot-starter-zebra` | Zebra（MySQL，美团 JDBC 封装） |
| `mdp-boot-starter-thrift` | Thrift RPC 服务端 |
| `mdp-boot-starter-crane` | Crane 定时调度 |

## 配置中心（Lion）关键配置项

| Key | 类型 | 说明 |
|-----|------|------|
| `crawler_thread_num` | Integer | 通用抓取线程池大小（动态调整） |
| `sitemap_thread_num` | Integer | Sitemap 线程池大小 |
| `screenshot_thread_num` | Integer | 截图线程池大小 |
| `js_spider_gray_unit` | Set | JS 抓取灰度白名单域名 |
| `js_spider_gray_ratio` | Double | JS 抓取灰度比例 |
| `camoufox_gray_ratio` | Map | Camoufox 指纹浏览器灰度比例（per domain） |
| `camoufox_cluster_ip` | List | Camoufox 集群 IP 列表 |
| `antibot_gray_ratio` | Map | Antibot 灰度比例 |
| `antibot_cluster_ip` | List | Antibot 集群 IP 列表 |
| `screenshot_cluster_ip` | List | 截图专属集群 IP 列表 |
| `screenshot_black_domain_list` | Set | 截图黑名单域名 |
| `sitemap_black_domain_list` | Set | Sitemap 黑名单域名 |
| `domestic_url_crawl_ratio` | Double | 国内 URL 抓取采样率 |
| `oversea_url_crawl_ratio` | Double | 海外 URL 抓取采样率 |
| `retry_grey_config` | Map | 重试灰度配置（retryGreyHost / retryGreyRatio） |
| `screenshot_timeout_ms` | Integer | 截图超时时间（毫秒） |
| `sitemap_stale_threshold_hours` | Integer | Sitemap 消息过期阈值（小时） |
