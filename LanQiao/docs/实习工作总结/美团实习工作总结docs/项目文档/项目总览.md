## 项目简介

美团 LLM 爬虫服务，负责接收抓取任务，通过多种 Downloader（HTTP/JS/Playwright/Camoufox/Antibot）抓取网页内容、Sitemap、截图+HTML，并将结果上传 S3 / 发送 MQ，供下游 LLM 训练数据使用。

## 技术栈

| 类型 | 技术 |
|------|------|
| 语言 | Java（server 模块用 JDK 17，client 模块兼容 JDK 8） |
| 框架 | Spring Boot（MDP 脚手架 mdp-parent 2.9.8） |
| 构建 | Maven 多模块 |
| 配置中心 | Lion（`@MdpConfig` / `@MdpConfigListener`） |
| 消息队列 | Mafka（`@MdpMafkaMsgReceive`，美团内部 Kafka 封装） |
| 缓存/存储 | Squirrel/Cellar（Redis，美团内部封装） |
| 对象存储 | S3（`mdp-boot-starter-s3plus`，Bucket: `llm-web-sitemap`） |
| 数据库 | Zebra（MySQL，HBase `mthbase-client`） |
| 浏览器自动化 | Playwright 1.54.0、Selenium 4.10.0 |
| HTML 解析 | jsoup 1.17.2 |
| CSS 解析 | ph-css 8.2.1 |
| 限流 | Rhino（`OneLimiter` / `ThreadPool`） |
| 监控 | CAT（`com.dianping.cat`） |
| RPC | Thrift（`@MdpThriftServer`） |
| 代理 | 国内/海外代理池，支持 Camoufox 指纹浏览器集群、Antibot 集群 |
