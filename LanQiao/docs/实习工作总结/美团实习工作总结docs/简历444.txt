## icon:project 个人项目

### 智析 RAG —— 基于 Spring AI 的企业级 RAG 对话系统

**技术栈**：Java 17 · Spring Boot 3 · Spring AI · PostgreSQL (pgvector) · Redis · RocketMQ

- **多通道并行检索**：CompletableFuture 同时发起全局向量检索与意图定向检索，两路结果合并去重后经 LLM 重排序，兼顾召回率与精准度
- **Chat / Embedding 双维熔断路由**：三态熔断器（CLOSED → OPEN → HALF_OPEN）+ 失败率阈值自动切换备用模型；Chat 通道引入首包探测，防止脏流写入用户端
- **意图树三级分类**：领域 → 类目 → 话题，LLM 分类后将检索范围收敛至目标向量空间，降低无效检索开销
- **持久化对话记忆与摘要压缩**：PostgreSQL 持久化多轮对话，超 10 轮后自动 LLM 压缩为摘要，解决长上下文 Token 超限问题
- **全流水线降级容错**：各阶段（检索 / 重排 / 生成）独立捕获异常并降级，单点故障不影响整体链路可用性
