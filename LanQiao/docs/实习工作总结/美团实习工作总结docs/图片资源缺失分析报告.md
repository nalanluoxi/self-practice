## 三、根因分析

### 问题1：srcset 变体缺失（最主要）

**原因：** 浏览器根据当前 viewport 宽度，只从 srcset 中选择最匹配的一个尺寸发起请求，其余变体永远不触发网络请求，onResponse 监听器收不到。

例如 viewport=1280px 时，`srcset="img-400w.jpg 400w, img-800w.jpg 800w, img-1280w.jpg 1280w"` 只请求 `img-1280w.jpg`，其余两个完全不请求。

**修复方案（3.7 节）：** `supplementImagesFromHtml` 解析 HTML 中所有 srcset 变体 URL，取差集主动下载。

### 问题2：第三方防盗链图片

**原因：** 某些第三方 CDN（globenewswire、广告平台等）通过校验 Referer/Cookie/Token 来防止盗链。Playwright 导航时携带完整浏览器上下文可以获取，但事后用 HttpURLConnection 二次下载时缺少这些上下文，被服务器拒绝（403/401）。

**影响评估：** 主要是新闻稿配图、广告图片，对页面主体内容还原影响较小。
