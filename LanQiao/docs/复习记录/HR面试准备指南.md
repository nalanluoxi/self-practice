# HR 面试准备指南

> 整理时间：2026-06-24
> 适用场景：校招/实习 HR 面（终面/初面）

---

## 一、HR 高频提问清单

### 1. 自我介绍类

| 问题 | 准备要点 |
|------|---------|
| 请做一个自我介绍 | 1分30秒以内，结构：学校→项目亮点→实习经历→求职意向，突出和岗位的匹配度 |
| 介绍一下你的实习经历 | 用 STAR 法则，重点说做了什么、产生了什么价值，数字化结果更有说服力 |
| 说说你最大的优点/缺点 | 优点要结合岗位；缺点说真实但可改进的，且已在改善中，禁止说"我太努力了" |

---

### 2. 求职动机类

| 问题 | 准备要点 |
|------|---------|
| 为什么选择我们公司？ | 提前调研：业务方向、技术栈、团队氛围、近期动态，说出具体原因而非泛泛而谈 |
| 为什么选择这个岗位？ | 对齐自身技能，说清楚"我能做什么"+"我为什么想做这个" |
| 你还投了哪些公司？ | 可以说同类型公司，表现出有目标感，不要说"我乱投的" |
| 如果同时拿到几个 offer 如何选择？ | 表达对本公司的倾向，提一个合理的衡量维度（成长空间/业务方向/团队氛围） |

---

### 3. 职业规划类

| 问题 | 准备要点 |
|------|---------|
| 三五年后你想做什么？ | 表达有方向感：技术深度/技术→业务/技术管理均可，但要和岗位一致 |
| 你的职业规划是什么？ | 不要说"我不确定"，也不要说"我要做架构师/CTO"，说近期1-2年的具体目标 |
| 你希望从这份工作中得到什么？ | 技术成长、业务理解、良好的团队协作环境，结合公司实际业务说 |

---

### 4. 性格与协作类

| 问题 | 准备要点 |
|------|---------|
| 你如何处理与同事/上级的分歧？ | 说具体案例，体现沟通能力、换位思考，结果是良性的 |
| 你在团队中一般是什么角色？ | 诚实回答，可以说执行者/推动者，佐以项目经历 |
| 你如何应对压力和高强度工作？ | 有方法（拆任务/时间管理/复盘），不要说"我不会有压力" |
| 你最失败的一次经历是什么？ | 说真实的，重点放在"从中学到了什么"，而不是事件本身 |

---

### 5. 意愿与稳定性类

| 问题 | 准备要点 |
|------|---------|
| 你能接受出差/加班/调岗吗？ | 根据实际情况诚实回答，表现出灵活性，但不要无条件答应所有事 |
| 你的期望薪资是多少？ | 校招一般看 offer 范围，可以说"以公司标准为准，我更看重发展空间" |
| 你什么时候能入职？ | 说清楚最早时间，如有前置手续（毕业/离职）直接说 |
| 你有其他 offer 吗？ | 可以说有在谈，不要撒谎，也不要过度炫耀 |
| 你为什么从上一家公司离开？（实习） | 说正面原因：项目结束/学业安排/寻找更匹配的方向，禁止说前公司不好 |

## 二、你应该主动准备问 HR 的问题（反问）

> 原则：体现你的认真和主动性，但不要提薪资福利相关（初面）

### 推荐问题

```
1. 这个岗位日常的工作内容是什么？主要和哪些团队协作？
2. 入职后的新人培养体系是怎样的？有没有 mentor 制度？
3. 团队目前的技术栈和主要业务方向是什么？
4. 这个岗位的成长路径大概是怎样的？
5. 您觉得在这个岗位上最重要的素质是什么？
6. 这次招聘的时间节点大概是怎样的？（问流程，显得有计划性）
```

---

## 三、面试"避雷"——这些问题不要问 HR

| 避免问的问题 | 原因 |
|------------|------|
| 加班多吗？有没有 996？ | 显得在意工作强度多于工作本身，第一印象差 |
| 工资多少？能不能涨？五险一金怎么算？ | 初面或 HR 面不合适，显得功利，等 offer 阶段再谈 |
| 公司最近有没有裁员计划？ | 质疑公司稳定性，HR 没有义务回答且会留下负面印象 |
| 你们公司在行业里排第几？ | 显得信息不充分，应该自己调研好 |
| 这个岗位能转正吗（实习问）？ | 暗示结果导向太强，应该问成长空间 |
| 我没什么问题了 | 显得不认真、对岗位兴趣不足，一定要准备 2-3 个问题 |

## 四、高危回答——这些话尽量不要说

### 负面表述

| 不好的说法 | 更好的替代 |
|-----------|----------|
| "我不知道/我不确定" | "这方面我还在学习，我目前的理解是……" |
| "我没什么缺点" | 说一个真实但已在改进的缺点 |
| "上家公司太差了/老板不行/同事关系差" | "因为……我希望寻找更适合自己成长的环境" |
| "随便，都可以" | 表达出有倾向有判断，才显得有主见 |
| "我就是想多赚钱" | "我希望在有竞争力薪酬的同时，找到能长期投入的方向" |
| "我之前也没做过，但我可以学" | 先说已有基础，再说学习意愿，顺序很重要 |
| "我的规划就是走一步看一步" | 说出具体方向，哪怕是短期的 |
| "这个问题我觉得你应该比我清楚" | 禁止反问面试官，会显得轻浮 |

### 行为雷区

- **打断面试官说话**：耐心听完再回答
- **回答过长超过5分钟**：结构化回答，控制时长，留空间给面试官追问
- **说话带口头禅**（那个、就是、反正）：提前练习，录音自查
- **对公司信息一无所知**：HR 面前必须做足调研，官网/招聘页/脉脉都要看
- **表现得过于紧张或卑微**：自信不等于傲慢，平和对话即可

## 五、HR 面结束时的收尾话术

```
感谢您今天花时间和我沟通，这次交流让我对岗位和团队有了更清晰的认识。
我对这个机会非常感兴趣，也很期待能有机会加入团队。
请问后续的流程大概是怎样安排的？我可以在 X 天后主动跟进吗？
```

---

## 六、校招 HR 面特别注意事项

1. **提前背熟简历**：HR 会对着简历问，自己说的每个项目都要能流利解释
2. **校招不谈钱**：等到 offer 环节，HR 会主动说，不要自己提
3. **表现对公司的了解**：提前看该公司最近新闻、业务、招聘页，说出具体细节
4. **诚实优于完美**：不会的不要硬编，说不了解但有兴趣深入学习
5. **结束后发感谢邮件（可选）**：大厂少用，中小公司可以发，体现诚意
