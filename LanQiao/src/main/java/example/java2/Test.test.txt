| 序号 | 测试条目               | 测试目的             | 判断标准                          |
| :- | :----------------- | :--------------- | :---------------------------- |
| 1  | **IP 地址自动获取**      | 验证 DHCP 服务器能分配地址 | PC 成功获取 IP，无 169.254.x.x      |
| 2  | **子网掩码正确性**        | 验证分配的掩码符合规划      | 显示 255.255.255.0（或规划值）        |
| 3  | **默认网关获取**         | 验证能获取对应 VLAN 的网关 | 网关为 SVI 地址（如 192.168.10.1）    |
| 4  | **DNS 服务器获取**      | 验证 DNS 参数下发正确    | DNS 指向 192.168.30.2           |
| 5  | **跨 VLAN DHCP 中继** | 验证各区域能获取不同网段     | 管理区/业务区/访客区网段隔离               |
| 6  | **地址租期正常**         | 验证租期配置生效         | show ip dhcp binding 显示租期     |
| 7  | **地址续租功能**         | 验证租期到期前能续租       | ipconfig /renew 成功            |
| 8  | **地址释放与重获取**       | 验证地址回收机制         | ipconfig /release 后 /renew 成功 |
| 9  | **连通性测试**          | 验证获取 IP 后能正常通信   | 能 ping 通网关和同网段设备              |
| 10 | **DHCP 服务器状态**     | 验证服务器运行正常        | Server 服务状态为 On，无冲突           |
